Homarr v2 dashboard. This is a new app, separate from Homarr v1. The default SQLite database moves by copying /appdata and keeping the same SECRET_ENCRYPTION_KEY. An external PostgreSQL database is not in /appdata. Stop v1, back up that database, then set the same DB_DIALECT and DB_URL and leave v1 stopped while v2 migrates it. MySQL is no longer supported; convert existing MySQL data to SQLite before starting v2. Not compatible with legacy Homarr (v0.x) data without migration.
